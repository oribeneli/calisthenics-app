## 1. What the evidence says, in one page

**Program choice (R1).** Nothing off the shelf fits an obese, untrained, hypermobile-shouldered person with 3 × 20–25 min and no bar. The r/BWF Recommended Routine needs a pull-up bar and ~60 min; Hybrid Calisthenics is 6 days/week with long rests and 3 × 50 gates; Convict Conditioning's tone and its bridge/handstand ladders are wrong for a lax shoulder; Overcoming Gravity asks the user to self-program, which is exactly the vagueness that makes this user quit. The evidence supports a hybrid: a two-week on-ramp (BWF Primer's idea of "never trained" as its own state), Hybrid-style leverage ladders as the exercise library, and the RR's explicit progression rule, on a full-body every-other-day schedule (Schoenfeld 2016, Grgic 2018 `[PR]`).

**Dose (R1, R3).** ACSM's prescription for deconditioned/obese beginners is one set of 8–12 reps to start `[G]`; the volume–strength gradient is shallow in novices (Ralston 2017 `[PR]`), so 2–3 sets × 8–12 at 2–3 reps in reserve, 60–90 s rest, is the ceiling that matters. Proximity to failure adds almost nothing to strength (Refalo 2024 `[PR]`) and, for a hypermobile shoulder, failure is where scapular control is lost. Scheduled deloads show no benefit in novices (two null studies `[PR]`); reactive easy weeks are the right tool.

**Ladders (R2).** The push ladder must begin with four serratus/scapular-control levels (wall serratus press, forearm wall slide, scapular wall push-up, kneeling scap-plus) because "shoulders collapse inward" is serratus anterior failing to hold protraction and upward rotation (Hardwick 2006, Ekstrom 2003 `[PR]`). Heavy strengthening is safe and effective in hypermobility spectrum disorder when end range is avoided (Liaghat 2020 `[PR]`). Wrists go neutral (fists on a towel, or elevated hands) because push-ups on an extended wrist raise radioscaphoid pressure `[PR]`. Without a bar, pulling has an honest ceiling (a low towel/doorframe row); prone Y/T/W raises are the highest-value pulling work for this shoulder, not filler. Early squats stay above ~60° knee flexion (patellofemoral load peaks near 90°, Wallace 2002 `[PR]`), entered through sit-to-stand. Core follows McGill: short repeated holds, no loaded spinal flexion. Static stretching before training and cool-down stretching for soreness are not supported (Cochrane 2011, Afonso 2021 `[PR]`).

**Safety (R3).** PAR-Q+ is the screen; BMI 30–35 alone is not a gate. Weeks 1–8 block jumping, burpees, lunges, full floor push-ups, dips and end-range shoulder work. Intensity ceilings: RPE 5–6 (weeks 1–2) → 6–7 (3–5) → 7 (6–8); the observable stop signal is "the last rep looks different from the first", not a self-estimated RIR (novice RIR error is ~4–5 reps `[PR]`). Sleep < 8 h roughly doubles injury odds in athlete cohorts `[PR]` (extrapolated); HRV/readiness-guided training matches fixed programming with less hard training `[PR]`.

**Adherence (R4).** A single missed day does not impair habit formation (Lally 2010 `[PR]`), but a zeroed streak is the "rule already broken" cue behind the what-the-hell effect; a rolling consistency percentage is the better metric. Tiny completed sessions preserve the habit; self-compassion predicts adherence, so a stopped set is logged as "8 of 10", never "failed". Daily weight noise (~0.35 %+) exceeds a realistic 0.5 %/week signal, so only a 7-day trailing average is shown. Waist by the NHANES protocol every two weeks. Implementation intentions ("if it is Tuesday 19:30, then I train in the living room") raise adherence (Gollwitzer & Sheeran 2006 `[PR]`). Protein 1.6 g/kg of goal body weight (Morton 2018 `[PR]`), stated as ~30 g per meal; 7+ h sleep (AASM `[G]`, Nedeltcheva 2010 `[PR]`); steps ramp +1,000/day every two weeks from a measured baseline, capped at 8,000.

## 2. Decisions

### 2.1 The program

| Decision | Choice | Why |
|---|---|---|
| Schedule | **3 identical full-body sessions per week, every other day** (user picks three fixed day + time + place slots) | Frequency ≥2×/week per muscle beats 1× at equal volume; a missed day costs a third of everything, not a whole pattern (R1 §3.1). If-then slots raise adherence (R4 A7). |
| Session shape | 4 min warm-up → 5 patterns (push, pull, squat, hinge, core), 1–3 sets each → 2 min optional wind-down. Target 20–25 min. | ACSM one-set start for obese beginners; volume gradient shallow in novices (R1 §3.2, §3.8). |
| Volume ramp | Week 0 (assessment): 1 set · Week 1: 1 set · Weeks 2–3: 2 sets · Week 4+: 3 sets | Obesity prescription starts at one set (R1 §3.2, R3 A1). |
| Reps / rest / tempo | 8–12 reps (or short holds) at 2–3 reps in reserve; 60–90 s rest; 2 s down, 1 s pause, 2 s up; **never to failure** | R1 §3.2–3.3, R2 global rules. |
| Intensity ceiling | RPE 5–6 weeks 1–2, 6–7 weeks 3–5, 7 weeks 6–8; stop signal = form change | R3 A3. |
| Week 0 | An onboarding week: PAR-Q+ screen, then a gentle "find your level" test per ladder: start at level 1, one clean set, step up only if it felt easy, capped at push P3 / pull L4 / squat S4 / hinge H3 / core C4 | Push control levels are prerequisites, not options (R2 §1, R3 A1). Caps keep weeks 1–8 inside the blocked-exercise rule. |
| Rest days | 5-minute mobility routine (cat–cow, open-book rotation, wall slides, glute bridges, easy walk) plus the six habit checkboxes | Dynamic mid-range movement is supported; static stretching and CARs are not (R2 §6). |
| On-ramp | Week 0 doubles as the Primer-style on-ramp: the Today screen introduces one pattern at a time across the first three sessions | R1 §4. |

### 2.2 The ladders (data: `src/data/program.json`, prose: `docs/PROGRAM.md`)

Adopted as specified in R2, with these edits:

- **Push (12 levels).** P1–P4 are scapular-control levels and must be passed in order; the assessment never places the user above P3. Every push level carries a "finish with a plus" cue and a "winging ends the set" fault. Floor levels default to fists on a towel.
- **Pull (10 levels).** Table rows (L9) are gated behind an in-app "sit test" checkbox; the ladder tops out at L10 and the app says plainly that a doorway bar or bands are the next step (month 3+).
- **Squat (10 levels).** S1–S5 keep knee flexion ≤ ~60–90°; split squats (S9–S10) are hidden until week 9 and removed if knee pain recurs twice.
- **Hinge (9 levels).** Any low-back ache drops the user to H6 (the towel-on-spine constraint drill) regardless of current level.
- **Core (11 levels).** Short holds only (cap 30 s); reps of short holds are added before levels. Planks default to forearms, never straight-arm on palms.
- **Mobility** is a fixed routine, not a ladder (nothing to progress).

Every ladder's level 1 is doable today by an obese untrained adult with this shoulder: wall serratus press, prone scapular retraction, shallow wall sit, glute bridge, dead bug with hands on knees.

### 2.3 The adaptive rules (engine: `src/engine/`, every rule a named, tested function)

| Rule | Trigger | Action |
|---|---|---|
| `PROGRESS_UP` | 2 consecutive sessions hitting the top of the rep/hold range on all sets of a pattern, with no "too hard" and no pain flag | +1 level; reset to the bottom of the range |
| `PROGRESS_HOLD` | Target met but a form-break / "too hard" was logged | Stay |
| `REGRESS_LEVEL` | 2 consecutive sessions with total reps < 70 % of target, or "too hard" pressed on ≥ 2 sets in one session, or joint/sharp pain in that pattern | −1 level (never below 1); copy: "found your level" |
| `REGRESS_IMMEDIATE` (in-session) | "Too hard" tap, or pain/numbness | Swap in the regression now for the rest of the session; log it as a level change, not a failure |
| `SLEEP_LOW` | sleep < 6 h | −1 set per exercise (min 1); no progression today; RPE cap 6 |
| `SLEEP_MID` | sleep 6–7 h or quality ≤ 2 | No progression today |
| `SORENESS_HIGH` | soreness ≥ 4 | If areas tagged: those patterns −1 level today only; otherwise −1 set everywhere; no progression |
| `SORENESS_PERSIST` | soreness ≥ 4 for 3 consecutive sessions | Hold levels, 50 % sets for one week |
| `MOOD_LOW` | mood ≤ 2 | Minimum session (1 set each, ~5 min); counts as a full session |
| `MIN_SESSION_ALWAYS` | any session | "Short version (5 min)" button always visible; counts as done |
| `DELOAD_REACTIVE` | 2 `REGRESS_LEVEL` events in 3 weeks, or 3 consecutive sessions with a form-break, or `SORENESS_PERSIST` | One week at 50 % sets (min 1), same levels, no progression. **No scheduled deloads.** |
| `MISS_1_SESSION` | one missed slot | Nothing; the miss is not mentioned |
| `MISS_1_WEEK` | 7–13 days without a session | −1 set for the first session back |
| `MISS_2_3_WEEKS` | 14–27 days | −1 level everywhere for one session; restore if the target is met |
| `MISS_4_PLUS_WEEKS` | ≥ 28 days | −2 levels (floor 1); re-run the health screen |
| `HARD_STOP` | chest pain, faintness, cold sweat, disproportionate breathlessness | End session; show the medical screen; block the next session until acknowledged |
| `SHAME_GUARD` | any regression or miss | UI copy never says failed/missed/behind; nothing resets |

Precedence: `HARD_STOP` > `REGRESS_IMMEDIATE` > `MISS_*` > `DELOAD_REACTIVE` > `SORENESS_*` > `SLEEP_*` > `MOOD_LOW` > `PROGRESS_UP`. At most one automatic level change per pattern per session. Every session shows one sentence explaining what changed and why.

**Resolved conflict.** R1 (≤ 3 weeks away → resume unchanged) vs R3 (14–27 days → one level down, then retest). Decision: R3, because the retest restores the level at zero cost if strength was retained, and the downside of guessing wrong is a shoulder that wings under load.

### 2.4 Screening (onboarding)

PAR-Q+ questions 1–7 verbatim plus four app items (shoulder instability, wrist pain/numbness, pregnancy, blood pressure ≥ 140/90). Any YES on 1, 2, 3 or 7 → hard gate ("see a doctor first", no skip). YES on 4 or 5 → recommend clearance. Shoulder YES → push locked at incline ≥ chest height for 4 weeks. Wrist YES → all hand-loaded work defaults to fists/forearms. BMI is never a gate. Re-screen after 12 months or a ≥ 4-week gap.

### 2.5 Metrics, habits, nutrition, sleep

- **Consistency**: rolling 28-day sessions done ÷ scheduled, shown as a percentage and a 28-dot grid. **No streak counter anywhere.**
- **Weight**: optional daily entry; chart shows only the 7-day trailing average as the bold line. Honest promise at onboarding: 0.5–1 % of body weight per week; reps roughly double in 8 weeks while the scale moves slowly.
- **Waist / hip / chest / arm**: every two weeks, with the 3-line NHANES protocol shown at entry.
- **Photos**: opt-in, local only, never displayed next to a number, no efficacy claim.
- **Six daily checkboxes**: protein at every meal (~30 g) · vegetables or fruit at two meals · no sugary drinks · a large glass of water before each main meal · 7+ hours in bed · walk target hit. No calorie or macro entry anywhere.
- **Protein**: 1.6 g/kg of goal body weight (BMI-25 weight for the user's height), shown once, then only as the per-meal checkbox.
- **Steps**: measure a 7-day baseline, then +1,000/day every two weeks, cap 8,000; 10,000 is never shown.

### 2.6 Rejected alternatives

| Alternative | Why not |
|---|---|
| r/BWF Recommended Routine as-is | Needs a pull-up bar and ~60 min; revisit as a graduation target after ~6 months |
| Hybrid Calisthenics as published | 6 days/week, 2–3 min rests, 3 × 50 gates — too slow to feel like progress in 3 × 25 min |
| Convict Conditioning | Uneven jumps, bridge/handstand ladders, and a tone that frames regression as weakness |
| Overcoming Gravity beginner template | Self-programming is the vagueness that makes this user quit |
| Start Bodyweight | Covered better by Hybrid; site unreachable for verification |
| Grease the Groove as the program | Weak, indirect evidence; presupposes a movement already done cleanly; kept only as the "minimum day" rescue |
| Scheduled deloads every 4–6 weeks | Two null studies in novices; a novice at 2–3 RIR is not accumulating fatigue a deload clears |
| Streak counter | Zeroed streaks trigger the what-the-hell effect; Lally shows single misses do not impair habit formation |
| Training to failure / AMRAP tests | Negligible strength benefit; scripted shame; scapular control is lost at failure |
| Static stretching warm-up, shoulder CARs, cool-down stretching | Not supported; end-range work is what a hypermobile shoulder should do least |
| Split routines | Frequency evidence favours full body for novices; a missed day would cost a whole pattern |
| Calorie counting | Out of scope by design; a single fibre goal matched a 13-component diet at 12 months |
| Table rows as the default pull | Most flat-pack tables fail a concentrated edge load at 100+ kg; gated behind a sit test |
| Full push-ups, dips, jumps, lunges, burpees in weeks 1–8 | Patellofemoral load ≥ 5 BW; wrist extension load; end-range shoulder |
| RIR as the stop signal | Novice RIR error ~4–5 reps; "the last rep looks different" is observable |

### 2.7 Known evidence gaps (do not over-claim in UI copy)

The "2 clean sessions" and "70 % of target" thresholds are coaching conventions, not trial-derived. Sleep–injury data come from adolescent-athlete cohorts. Progress photos have no adherence evidence at all. No study has tested readiness rules in an obese home-training population; the engine is a falsifiable first version and logs every rule firing so the rules can be revised against real data.

*Not medical advice. A hypermobile shoulder with symptomatic winging is worth one physiotherapy assessment before starting; the app says so in onboarding.*
